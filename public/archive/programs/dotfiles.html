What are Dotfiles?

Dotfiles are a collection of program configurations that allow others to see your personal configurations. This allows for other people to copy your configurations which then enables those people to further modify your configurations or to see how to configurations work for certain programs.

Features of my Dotfiles

The main feature of my Dotfiles is that I have an install script that either turns your existing system to become more like mine, or takes a newly installed system and then turns it into mine! As of right now I only have install scripts for Debian and Arch Linux. However, since I do not use Arch Linux anymore I cannot guarantee how good the Arch Linux install script is anymore.

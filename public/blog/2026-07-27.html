What have I been up too?

Since my last post I have done a few bits. For example me and my friend Gositi have started a project together! It is called ESSE. ESSE starts for the Experimental System Shell Environment and it means something in Swedish, but I am not of that persuasion. So far ESSE has been going well, me and Gositi split the cost of it and manage it together as sudoers and so far no arguments which is good. We both do our own little bits. I focus on the front end website which is the homepage, the management of the web server and some security bits. It is a bit scary how many bots try and hack into the server.

ESSE project ideas

So for ESSE I do have some ideas, of which I will go into detail about. My first idea is programming some sort of bulletin board system for the users on the server. So any user can post something and you can comment on what has been posted. I will guess that would involve the use of some sort of database. Another idea would be having some form of a media server on ESSE like Jellyfin. However, sadly as of right now we do not have enough storage to warrant. There are countless things I want to do with ESSE, but we just need more people so we can grow it for me to do these things. Hopefully one day.

Dotfiles

In the future I think it would be good if I made a universal script which would detect which package manager you are using and just uses that for installing the packages.

Maybe I will put it in my dotfiles. I do have a custom dotfils install script for myself.
